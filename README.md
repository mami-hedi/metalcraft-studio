# MetalCraft Studio

Site vitrine pour SAM MECA — construction métallique, chaudronnerie, charpente métallique, confection de citernes et remorques.

## Développement

\`\`\`sh
git clone https://github.com/mami-hedi/metalcraft-studio.git
cd metalcraft-studio
npm install
npm run dev
\`\`\`

## Build

\`\`\`sh
npm run build
\`\`\`
